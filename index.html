AI connection help

For a local copy, run npm start from the project folder, then open http://localhost:3000.

The site owner must copy .env.example to .env, fill in OPENAI_API_KEY, and restart the server. Keep the key in the server configuration.

After setup, choose Check connection. To turn AI on after opting out, select Use connected AI.
